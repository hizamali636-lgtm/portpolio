# Hizam Ali — Full Stack Developer Landing Page

Files:
- index.html
- style.css
- script.js

## Run
1. Keep all three files in the same folder.
2. Double-click `index.html` or open it with VS Code Live Server.

## Replace your photo
Inside `index.html`, search for:
    YOUR PHOTO

Replace the `.portrait-placeholder` block with:
    <img src="assets/profile.jpg" alt="Hizam Ali">

Create:
    assets/profile.jpg
